# SCORE

**On-chain AI powered credit intelligence.**

SCORE is a real-time wallet risk scoring system for Base-based lending protocols.

## Phase 0: MVP (Weeks 1–8)

- **Week 1**: RPC query + feature extraction
- **Weeks 2–3**: REST API endpoint
- **Weeks 4–5**: Smart contract on Base Sepolia
- **Weeks 6–7**: Lender validation
- **Week 8**: Polish + Base Ecosystem Fund application
