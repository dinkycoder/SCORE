# SCORE Phase 0: MVP Roadmap (Weeks 1–8)

## Overview
Phase 0 validates the credit signal on Base with real lenders.

## Timeline

### Week 1: RPC Query + Feature Extraction
Goal: Query Moonwell wallet state, compute financial features.

### Weeks 2–3: Flask API Endpoint
Goal: Expose wallet scoring via REST API.

### Weeks 4–5: Smart Contract
Goal: Store scores on-chain, emit events.

### Weeks 6–7: Lender Validation
Goal: Deploy on Base Sepolia, get 2–3 lenders to test.

### Week 8: Polish + BEF Application
Goal: Prepare for funding ask.
